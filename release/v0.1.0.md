Initial public distribution of 480 existing tidal-evolution catalogs (`Sim_0000`–`Sim_0479`).

Download `tidaltrack-catalog-v0.1.0.zip` and `SHA256SUMS` from the release assets. The ZIP includes all original `subhalo_properties.hdf5` files, a per-file SHA256 manifest, simulation parameters and README. No particle snapshots or intermediate files are included. Catalog bytes are preserved exactly.

Known limitations: `HBT/BoundR200CritComoving` contains infinities and should not be used as a physical radius; derived fields contain NaNs; JSON particle counts often precede IC pruning. The metadata includes actual IC-header counts separately. Scientific definitions and provenance will be refined in subsequent versions.

This is an initial distribution, not a certification that every field is scientifically valid. A Zenodo DOI has not yet been assigned.
